# Gameplay Notes

Use this file for rough ideas, mechanics, and balance notes.

## Pillars

- Weighty 3D shooter movement.
- Punchy ranged combat.
- Readable enemy silhouettes.
- Co-op-friendly level design later if the project grows that way.

## First Prototype Goals

- Player capsule with camera look and movement.
- One hitscan weapon.
- One target dummy enemy with health.
- One graybox arena scene.
